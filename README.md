# Stress-Test Géopolitique : Risque de Crédit 

## Objectif

Quantifier l'impact d'un choc géopolitique sur le risque de crédit souverain italien.

## Méthodologie

### Étape 1 : VAR bayésien
Propagation d'un choc d'incertitude aux variables macro-financières (PIB, chômage, spreads).

### Étape 2 : Satellite Merton-Vasicek
Conversion des variables macro stressées en probabilités de défaut via une formule fermée.

### Étape 3 : Résultats
Application à l'Italie : la transmission du choc au risque de crédit est graduelle, avec un pic décalé de plusieurs trimestres.
